# McD Breakfast Variety · 麦当劳早餐不重样 Skill

一个让每天早餐不重样的麦当劳点单 skill。通过麦当劳 MCP 查询历史订单做去重，结合早餐时段菜单和当前星期，挑一份与近期不重复的早餐**套餐**并完成下单（到店自取或麦乐送）。

## 口令

```text
我要麦当劳早餐不重样
```

可带参数：

```text
我要麦当劳早餐不重样 到店        # 到店自取
我要麦当劳早餐不重样 外送        # 麦乐送到家
我要麦当劳早餐不重样 预算20      # 控制预算（元）
我要麦当劳早餐不重样 清淡        # 口味/偏好提示
```

## 核心逻辑

1. 获取当前时间，判断是否在早餐供应时段
2. 查历史订单做去重（避开最近 N 天点过的主餐）—— "不重样"的核心
3. 定位门店（到店自取 / 麦乐送）
4. 拉早餐菜单，**优先选套餐**
5. 算价（含可用优惠券）
6. 下单，返回支付链接（支付由用户在麦当劳 App 完成）

详见 [`skills/mcd-breakfast-variety/SKILL.md`](skills/mcd-breakfast-variety/SKILL.md)。

## 依赖

需要配置一个提供麦当劳点单能力的 MCP server（查门店 / 查餐品 / 算价 / 下单 / 历史订单等工具）。本仓库仅包含 skill 定义，不含任何凭证。
